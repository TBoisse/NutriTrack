# Summary

This project aims to facilitate dieting and diet evaluation. It proposes full mineral, vitamins and macros check for a meal, the ability to save a recipe or a composed food and the ability to get back all the proportion of a mixed meal.

# Objectives

This project was designed for its utility in the daily life and for the competences in web application.

# Usage

Flask server through `app.py` and requirements in `requirements.txt`.
